Technical work that demonstrates practical skills in various topics in engineering.

2023

Optical Triangulation for Imaging Sulcus Vocalis

Investigated optical triangulation techniques for imaging sulcus vocalis. Designed mechanical and optical components in SolidWorks, produced 3D-printed prototypes, and simulated optical paths in ZEMAX.

2023

Sleep Stage Classification on Sleep-EDF

Implemented an end-to-end pipeline for automatic sleep-stage scoring using the Sleep-EDF Expanded dataset (PhysioNet). The workflow covers raw polysomnography loading (MNE / pyEDFlib), epoching, feature extraction (spectral, entropy and time-series features via tsfel, tsfresh, antropy, etc.), and supervised classification of the five standard stages (Wake, N1, N2, N3, REM). Group-aware cross-validation and learning-curve analysis were used to assess generalization across subjects.

2023

Robot Car Movement Controlled by Eye-Tracking

Developed a prototype system in which a mobile robot car is steered by eye-gaze direction. Eye-tracking data were mapped to motion commands, enabling hands-free directional control.

2022

Diabetes Prediction with Exploratory Data Analysis

Developed a machine-learning pipeline for early prediction of diabetes mellitus using the widely studied PIMA Indian Diabetes Dataset (768 patients, 8 clinical features). After extensive exploratory data analysis, five supervised algorithms were trained and compared: Naïve Bayes, Decision Tree, K-Nearest Neighbors, Support Vector Machine and an Adaptive Boosting ensemble. Hyperparameters were optimized systematically. KNN reached the highest performance (accuracy and F1 ≈ 0.99 on the held-out test set), followed closely by the ensemble and Naïve Bayes.

Code available on GitHub.

2021

Obstacle-Avoiding Robot with Arduino

Designed and built an autonomous obstacle-avoiding mobile robot. The system used ultrasonic sensors for distance measurement and an Arduino microcontroller for real-time control of differential-drive motors. Basic reactive navigation logic enabled the robot to detect and circumnavigate obstacles in unstructured indoor environments.
