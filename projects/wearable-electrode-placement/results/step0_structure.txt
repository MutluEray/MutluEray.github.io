--- bids_dataset/README ---
Ear-SAAD BIDS dataset

This dataset contains simultaneous scalp, around-ear, and in-ear EEG recordings of 15 participants during a selective listening task for auditory attention decoding.
A detailed description of the dataset and the protocol can be found in the paper: '

Data are epoched in 10-minute trials. The events/triggers file can be used to extract the relevant trials.

Data are organized according to the BIDS specification (v1.10.0).
