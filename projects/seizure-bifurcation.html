Seizure Onset as a Bifurcation: An Excitatory/Inhibitory Network Model

Seizure onset modelled as a switch between two stable states in a 3,750-neuron excitatory/inhibitory network.

Code on GitHub Read the full write-up
Year
2022
Data
Simulation (Brian2)
Methods
Spiking networks, rate models, bifurcation analysis
Status
Re-analysed and written up in 2026

A simulation study that treats seizure onset as a dynamical transition instead of a detection problem. Starting from a published excitatory/inhibitory network (Kim & Nykamp, 2017; originally written for Brian 1), I ported it to Brian2 (3,750 conductance-based Morris–Lecar neurons) and tested whether interneurons that stop firing under strong input (depolarization block) give an abrupt, hysteretic and triggerable switch from a calm state to a seizure-like state as the external drive is ramped up and back down. At a fixed drive the network sits in either state depending on its history, and a 100 ms pulse moves it from one to the other for good. A two-population rate model built from the measured neuron responses reproduces the two stable states and the unstable state between them, and removing the interneuron shutdown removes most of the bistable window. Adding a slow adaptation variable makes the high state switch itself off and repeat.

The transition

Left: spikes of excitatory (blue) and inhibitory (orange) neurons. Top right: population rates and the input drive (dashed, right axis). Bottom right: excitatory rate against drive. Raising the drive makes the network jump to a high-rate state near 1.5 kHz as the interneurons shut down; lowering it, the state persists until about 0.56 kHz, so between the two thresholds the same input can give either state (EK = −90 mV).

A replication and extension of Kim & Nykamp, J. Comput. Neurosci. 2017 (ModelDB 189346). The rate model is a simplification built from the measured neuron responses; the spiking network is the reference. The repository also contains an exploratory, qualitative comparison with public human Utah-array recordings (one subject, three seizures; Scientific Data 2025, EBRAINS): compatible with, but not a validation of, the model.
