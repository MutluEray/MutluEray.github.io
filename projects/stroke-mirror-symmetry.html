Does the Brain’s Left–Right Symmetry Survive Stroke? Testing a Mirror-Symmetry Prior for Motor-Imagery BCIs

Does a left–right symmetry prior still help motor-imagery decoding after stroke? In healthy subjects it carries real information; in patients it no longer helps.

Code on GitHub Read the full write-up
Year
2023
Data
50 acute stroke patients, 50 healthy subjects
Methods
Group equivariance, Riemannian tangent space
Status
Re-analysed and written up in 2026

Many motor-imagery decoders assume that the two hemispheres mirror each other: imagining the left hand should look like imagining the right hand, reflected across the midline. In the language of geometric deep learning, the decoder is made equivariant to a two-element symmetry group, so mirroring the EEG flips the decision. I tested whether this prior, designed around healthy brains, still helps after a stroke. The data are 50 acute stroke patients and 50 matched healthy subjects, with the same 29 channels and pipeline. The decoder is a Riemannian tangent-space model in which the mirror splits every feature into a part that flips sign and a part that does not, so exact equivariance means keeping only the first. The key control replaces the real left–right pairing with 200 random pairings of the same shape. If the real mirror only helped by constraining the model, random mirrors would help just as much.

The decoder is forced to treat each pair of linked electrodes as mirror images. With the brain’s real left–right pairing (C3↔C4, …) this helps a little; with a random pairing it hurts. Pick a group, then shuffle a random pairing and see where it lands.

What it means: in healthy subjects the real mirror carries real information. A wrong symmetry costs about 2.7 points, while the right one adds about 1 point over no prior. After stroke, the left–right motor signature itself is about six times weaker, so the prior has little to work with. It no longer helps, but the real mirror still beats 98% of random ones on the central channels (p = 0.025). Flipping each patient so the affected side is always the same (canonicalization) gave no benefit either. An apparent +3-point gain in stroke came from three high-amplitude recordings and disappeared when they were removed; stroke results are shown without them. Two caveats limit the stroke result: left-versus-right decoding in these patients is close to chance (54–56%), and the healthy and stroke data come from different recording setups.

Built on the geometric deep learning module of MIT 6.S980 Machine Learning for Inverse Graphics (self-study). Data: acute stroke motor imagery, Liu et al., Sci. Data 2024 (CC BY 4.0); healthy reference, PhysioNet EEG Motor Movement/Imagery (Schalk et al., 2004). Prior symmetry methods: EEGSym and Channel Reflection, both evaluated on healthy data. Limitations: acute patients with mostly subcortical or brainstem lesions; linear decoder only.
